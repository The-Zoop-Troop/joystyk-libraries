# Core beliefs

1. Repository knowledge is the system of record. Keep a short map and indexed documents.
2. Beads owns plans, dependencies and discoveries; evidence survives sessions and machines.
3. Enforce architecture and release boundaries mechanically, with actionable failures.
4. Keep deterministic models pure and inject randomness or time explicitly.
5. Parse external data at the boundary; do not replace a schema with a type assertion.
6. Prefer one shared mechanism over repeated host-specific helpers.
7. Reproduce bugs before fixing them and prove the regression fails for the right reason.
8. Validate installed artifacts independently of source workspaces.
9. Improve missing documentation and tools rather than relying on repeated human reminders.
10. Record quality honestly. Passing tests do not prove publishing permissions or live setup.
